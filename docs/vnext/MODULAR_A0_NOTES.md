# Modular A0 implementation experiment

This separate adapter consumes only the canonical TypeSpec IR and the official TypeSpec OpenAPI3 projection. It emits a Java 21 / Spring Boot 4.1.1 app with shared Spring JDBC domain operations, a contract-derived entity manifest and PostgreSQL 16 baseline DDL. The generated application does not require ProtocolIA at runtime and never imports JHipster. Initial profile is deliberately fail-closed to one entity with a string public identity, the six declared Taller operation kinds and two server-side capabilities. Run Dockerfile.a0-modular in isolation; build success must be accompanied by actual HTTP and DB test logs before making functional claims. OpenAPI Generator and a declarative React frontend are not integrated in this initial fallback experiment. This is not yet an accepted A0 adapter or production deployment.
