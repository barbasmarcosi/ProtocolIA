## Official JHipster blueprint integration surface

Official JHipster 9.x supports side-by-side and local blueprints
(https://www.jhipster.tech/modules/extending-and-customizing/).
Those hooks can customize generated files but **do not create contract
semantics automatically**. Observed incompatibilities span the generated
Java controller route + identifier type, React route/ID selection, list
pagination shape, missing domain transactions, and operation-scoped
authorization. A ProtocolIA extension would have to assume ownership of
the essential resource server and resource UI surfaces, not simply add
a field/constraint to JDL. This is a high-maintenance structural overlap
with the alternate modular approach, not a proof of mathematical
impossibility.

## Veredicto y alcance

**JHipster 9.4 estándar: NO-GO contractual.** Funciona como CRUD/React/PostgreSQL, pero no respeta identidad externa, operaciones especializadas, permisos ni respuestas del Taller. Las extensiones oficiales existen, pero exigirían reemplazar controladores, rutas React, roles y operaciones; eso duplica gran parte del motor.

**Fallback modular: GO inicial, A0 PASS.** Un mismo TypeSpec/IR produce dos aplicaciones funcionales mononentidad; JHipster no forma parte del runtime. El generador oficial OpenAPI 7.26 produce interfaces y DTO compilados, pero la ejecución HTTP está vinculada a un despachador de semántica reutilizable, sin implementación de las interfaces como delegates. Este matiz no bloquea A0, pero debe resolverse en A1 si se adopta como arquitectura de interfaces.

A1: ejecución de primitives/DB/auth en el perfil Taller validada parcialmente; faltan controles de migraciones, contratos más amplios y seguridad lista para producción. A2: React y Chromium reales validados; faltan CLI one-command, estados de permisos/errores y empaquetado integral. A3 NestJS, A4 multi-entidad FK y A5 evolución segura siguen NO INICIADOS. El profile Basic demo es opt-in; npm audit advirtió dos dependencias vulnerables sin triage. No se desplegó una app generada públicamente, no hubo merge ni modificaciones al demo manual.
