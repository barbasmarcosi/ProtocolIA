# ProtocolIA v1.0.0 — línea funcional del generador

**Fecha:** 2026-10-20

**Categoría:** v1 acotada para ingeniería / developer preview. No implica certificación de producción.

## Características verificadas

ProtocolIA genera, desde contratos TypeSpec validados y su IR/OpenAPI, aplicaciones con PostgreSQL, Docker Compose y UI React para dos objetivos: Spring Boot/Java 21 y NestJS. Se generan validación contractual, capacidades de acceso, auditoría y operaciones de negocio soportadas por cada contrato.

La colección de documentos versionados incluye creación de 1 a 20 renglones, filtrado por identidad de cabecera, sumas SQL, altas, PATCH auditados, baja de renglón, reemplazo completo transaccional, ETag/If-Match, recuperación ante conflictos y cierre irreversible. La UI React generada maneja operaciones individuales y cierre. El editor visual por lotes aún no está implementado.

## Requisitos

Node.js 24, npm, TypeSpec 1.17.0, Docker/Compose y Java 21/Maven para el target modular-spring. Una generación ejemplar:

~~~sh
npm ci
npm run app:build -- examples/vnext/dynamic-order-versioned --target nestjs --out /tmp/protocolia-v1
~~~

El comando general app:test aún no entiende If-Match. La aceptación de este contrato requiere el workflow de versión.

## Garantías que no se incluyen

- No existen migraciones automáticas in-place, reversión comprobada de esquemas o backups de producción.
- No se garantizan permisos basados en dueño/instancia para todos los perfiles; existen controles de capacidades por recurso.
- No está implementada la UI de reemplazo en bloque, ni un examen de accesibilidad amplio.
- El CLI genérico de conformance no maneja el protocolo ETag/If-Match.
- Sin garantía de alta disponibilidad, restauración/rollback productivo, observabilidad completa o pruebas de penetración.
- No todos los contratos TypeSpec ni cualquier requerimiento de negocio pueden producir sistemas completos.
- No se garantiza compatibilidad entre futuras versiones de artefactos sin un proceso de migración.

**Política:** esta versión es una referencia técnica reproducible, no autorización para almacenar datos productivos sensibles sin evaluación adicional.
